# Fidelity register

Reference [paper](https://arxiv.org/html/2602.07508v1) and [authors' repository](https://github.com/AMAAI-Lab/relational-ai). This code is independently written; no upstream reuse license is assumed.

| Element | Current prototype | Remaining difference/work |
|---|---|---|
| Two partners; PS/DS/BP | Secret participant links; server condition | Implemented |
| Phase sequences | Eight/five/three phases | Implemented |
| Prompt content | Paraphrased topics and reconstructed instructions | Reconcile exact wording/tone |
| Rapport | One compact activity | Source rapport is richer |
| Driver/Analyzer | Separate API instructions/calls and phase summaries | Scripted demo is not LLM behavior |
| Model | Source snapshot configured | Paid live calls/access unverified |
| Platform/modality | Browser text or optional GPT-Live voice | Telegram departure; voice adds modality/model/turn-taking changes |
| Participation setting | Loopback server, two local tabs | Secure remote deployment pending |
| Advancement | Both partners Ready or Skip | Verify source completion semantics |
| Closing recap | Displayed recap; corrections logged in chat | Text itself not automatically rewritten |
| Surveys | External checklist/linkage | Full questionnaires/scoring pending |
| Allocation | Demo shuffled blocks of three/manual debugging | Concealed research schedule pending |
| Consent | Fictional-data demo acknowledgment | Approved research consent pending |
| Logs | UTC phase/speaker events; manual JSON export | In-memory; approved persistence pending |
| Analysis/interviews/coding | Draft procedures | Registration, training, instruments pending |
| Participant response/security | Stop/pause, local access, secret links | Distress procedure and remote hardening pending |
